****OpenVista: Data Analysis and Visualization for Open Datasets****

**Overview**

OpenVista is an open-source initiative aimed at exploring and visualizing real-world datasets using data cleaning, machine learning, and business intelligence techniques.
Each team member contributed to a different dataset, building complete data pipelines — from preprocessing to dashboarding — to make data insights accessible and interactive.

**Objectives**
- To contribute to an open-source repository by enhancing existing data analysis projects.
- To perform end-to-end data workflows: cleaning, EDA, model building, and visualization.
- To demonstrate real-world analytical and predictive modeling skills.
- To design dashboards for clear, actionable insights using Power BI and Python visualizations.

**Technologies Used**
- Languages: Python
- Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- Visualization Tools: Power BI, Tkinter (for UI-based ML apps)
- Version Control: Git & GitHub

**How to Run the Projects**
1. Clone the repository:
git clone https://github.com/SayaliNimbalkarr/beginner-data-analysis-project.git

2. Switch to a project branch, e.g.
git checkout weather-cleaning

3. Open the respective Jupyter notebook and run all cells.

4. For dashboards, open .pbix files in Power BI Desktop.
